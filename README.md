# How to run httpflood?
Clone the project

```bash
  git clone https://github.com/fahise/httpflood.git
```

Go to the project directory

```bash
  cd httpflood
```

Install GoLang and Requirements

```bash
apt update && apt install nodejs
```

Start the application

```bash
  node httpflood.js [URL] [TIME] [proxy.txt] [THREADS]
```



## Example

```bash
  node httpflood.js http://example.com 60 proxy.txt 300
```
